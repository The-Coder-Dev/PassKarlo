# 11 — Product Roadmap

## Phase 1 — Design / Presentation

Current priority:
- Figma implementation
- Homepage
- Navigation
- Placeholder search
- Institute cards
- Career UI
- Career detail UI
- Add Your Institute popup
- Responsive design
- Premium visual polish

No complicated backend functionality.

## Phase 2 — Core Backend

Introduce:
- PostgreSQL
- Drizzle
- Institute database
- Career database
- Admin authentication
- Admin CRUD
- Draft/publish
- Real institute profiles

## Phase 3 — Search

Introduce:
- Search
- Filters
- Location
- Course filtering
- Institute type
- Pagination
- Ranking

## Phase 4 — User Features

Potentially:
- Accounts
- Saved institutes
- Enquiries
- Notifications
- Reviews

## Phase 5 — AI

Potentially:
- AI education search
- Career recommendations
- Personalized discovery
- Natural-language queries

## Roadmap principle

Do not build complexity just because the product may need it someday.

Build today's requirement cleanly while leaving clear extension points for tomorrow.
